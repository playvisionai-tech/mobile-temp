# Build / Release

## EAS builds
Six scripts, one per profile × platform (profiles are defined in `eas.json`):

- `pnpm build:development:ios` / `pnpm build:development:android`
- `pnpm build:preview:ios` / `pnpm build:preview:android`
- `pnpm build:production:ios` / `pnpm build:production:android`

They shell out to `eas build`. **`eas-cli` is not installed** — not a
dependency, not in `node_modules/.bin`. Install it globally
(`npm i -g eas-cli`) or the scripts fail with "command not found".

## Version and release
- `pnpm app-release <patch|minor|major>` → `np`: bumps the version in
  `package.json`, prebuilds so the native version matches, tags, and pushes.
  Normally triggered from the **New App Version** workflow
  (`.github/workflows/new-app-version.yml`, manual dispatch), not run locally.
- GitHub release notes are generated automatically from the pushed tag by
  `.github/workflows/new-github-release.yml`.

There is no changelog script and no `CHANGELOG.md` in this repo — release notes
are generated by GitHub.

## Before releasing
`pnpm check-all` (lint → type-check → translations → test → check-specs →
doctor). `SKIP_DOCTOR=1` drops the doctor step when offline.
